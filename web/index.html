Run a benchmark batch

2,000 generated references against 20,000 generated papers. Every reference has a known label, so accuracy is measured too. The data is created automatically on the first run.

Running the C++ program…

The busy batch has many fake references. Each one forces a full fuzzy search, so it is much slower. That uneven cost is the load-imbalance problem this project solves with parallel threads in the next phases.
